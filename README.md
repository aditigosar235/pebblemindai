# Pebble Mind

Pebble Mind is a local-first AI workspace for iPhone and iPad. It helps people use supported Apple and GGUF models on their own devices, with a clear model library, streaming chat, Markdown, conversation history and search, storage controls, and supported attachments.

The local workflow does not require an account or API key. Web search is separate and optional; when enabled, the configured search service receives the query and the app shows sources. Conversations, prompts, responses, attachments, downloaded models, and preferences are kept on-device according to the app’s privacy description.

## For developers and local-model users

Pebble Mind supports a first-version workflow for choosing compatible models, checking device-readiness information before downloading, and working locally on Apple platforms. Pro adds custom model importing, expanded model management, advanced generation controls, configurable search domains, local data transfer, searchable logs, and context compaction.

This repository contains the static marketing site and campaign content. Product behavior and platform implementation live in the associated application repositories.
