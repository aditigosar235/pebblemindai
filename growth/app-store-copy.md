# App Store marketing copy pack

Use in App Store Connect only after checking the current listing and build. This pack is written for ordinary iPhone/iPad users first, with enough detail for local-AI users. Keep the existing product facts as the source of truth.

## Recommended metadata

**Subtitle**

> Private AI on your iPhone

**Promotional text**

> Try supported AI models locally on iPhone and iPad. No account or API key is required for the local workflow, and web search is optional.

**Description**

> Pebble Mind makes local AI easier to try on iPhone and iPad.
>
> Choose a supported model, let it prepare on your device, and start with a small question. Use it to summarize a note, rewrite a message, explain a paragraph, brainstorm ideas, or ask about a supported document or image.
>
> The local workflow does not require an account or API key. Chats, prompts, responses, attachments, downloaded models, and preferences are described as stored locally. Web search is optional; when you turn it on, the configured search service is used to find current information and sources.
>
> Pebble Mind includes a model library with details about model size, availability, and device readiness. Start with a model that fits your device and workflow. Larger models may use significant storage, memory, battery, and heat.
>
> Free to start. Pebble Mind Pro is a one-time unlock for additional local-model controls, custom model importing, expanded model management, and other advanced tools.
>
> AI can make mistakes. Check important information independently.

**Keyword candidates**

> private ai,local ai,on-device ai,iphone ai,ipad ai,local llm,ai chat,privacy

Remove any keyword that conflicts with the current App Store rules or the actual listing. Do not use “fully offline” or equivalent wording that overstates the optional web-search boundary.

## Screenshot sequence

1. Clear promise: “Private AI on iPhone and iPad” with the app’s first screen.
2. Model choice: show the model library and readiness/device-fit information.
3. First success: show a harmless prompt such as “Summarize this note.”
4. Everyday value: show rewrite, explanation, or brainstorming using safe sample content.
5. Choice boundary: show local chat and the optional web-search control separately.
6. Power-user depth: show model management or custom importing only if the current build supports it.

Every screenshot must use the actual shipped app and current OS, avoid performance numbers, and keep text readable without technical jargon.
