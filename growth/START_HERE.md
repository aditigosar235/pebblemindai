## Run one content cycle

1. Read `product-facts.md` and `../MARKETING_ACCOUNT_INVENTORY.md`.
2. Check the live App Store listing and current iOS source before making claims.
3. Select the next slot from `posting-queue.csv`; do not invent a new channel or cadence.
4. Select the audience named in that slot: everyday privacy-conscious users, Apple users/families, or developers/local-AI users.
5. Write the complete website article under `growth/blog/` and add/update its public HTML page in the site root.
6. Create one customized draft each for Reddit, X, LinkedIn, and short video under `growth/outbox/YYYY-MM-DD/`.
7. Create the seven localized versions when the topic is suitable for general users; obtain fluent review before publishing.
8. Check the relevant community rules and add the correct App Store URL. Disclose that the account is the official Pebble Mind brand account when relevant.
9. Record every asset in `content-log.csv` before publication, using `DRAFTED` or `READY_SITE_FILE` until a real URL and analytics are available.
10. Publish only through authenticated accounts. If access is missing, report `DRAFTED — HUMAN PUBLISH REQUIRED`.
11. After publication, record the real post URL, platform-reported reach/impressions, clicks, installs, and replies. Never estimate reach.

## Account setup order

Use the account list in `../MARKETING_ACCOUNT_INVENTORY.md`. Start with the dedicated Google identity for the base email, then reserve Pebble Mind brand handles on X, Reddit, YouTube, Instagram, TikTok, Bluesky, Mastodon, Dev.to, Hashnode, and LinkedIn Company Page. Product Hunt is the exception: it requires a real person’s maker account, so it must not use a fabricated brand identity.

CAPTCHA, email verification, and 2FA must be completed by the authorized account owner. The subagent may continue after authentication but must never log passwords, recovery codes, session cookies, or tokens.

## Publishing rules

- Start with the benefit in plain language; put technical detail second.
- Mention iPhone/iPad only for this campaign.
- Say “local workflow” and “web search is optional”; do not say “fully offline.”
- Use one CTA per post: https://apps.apple.com/us/app/pebble-mind/id6799536766
- Do not mass-post identical copy, mass-DM, automate replies, create fake accounts, buy reach, or invent traction.
- On Reddit, answer the question first and post only where the rules permit self-promotion.

## Completion test for each cycle

The cycle is complete only when the article, platform adaptations, localized assets, content-log rows, actual post URLs or human-publish status, and measured results are all recorded.
