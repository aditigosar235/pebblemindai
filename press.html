Pebble Mind · Press information

Private AI,

Pebble Mind is a free-to-start iPhone and iPad app for chatting with supported AI models locally. No account or API key is required for the local workflow. Web search is optional and opt-in.

Use the wording on this page as the approved short description. Please ask before using performance numbers, unsupported device claims, or statements that imply Apple endorsement.

Short description

Pebble Mind is a private, local-first AI workspace for iPhone and iPad. Choose a supported model, start a conversation on your device, and keep control of when optional web search is used.

Key facts

  • Platform: iPhone and iPad
  • Minimum requirement: iOS 26 / iPadOS 26
  • Free to start; optional Pebble Mind Pro one-time unlock
  • Local chat with supported Apple and GGUF models
  • Optional web search with visible sources
